# Shelf 独立目录试用记录

2026-11-18，在独立的操作系统临时目录运行 Shelf。该目录只包含试用页面、完整 skill 与静态文件服务脚本；不依赖 PathBlender、Stillroom 的应用代码或作者私有文件。

这是实现者阅读 skill 后进行的自试用，不是另一位模型的盲测。`trial/REQUEST.md` 保存需求，`trial/app.mjs` 和 `trial/index.html` 保存实现。`npm run trial` 重新组装该独立目录；组装成功本身不等于运行验证。

实际使用内置 Chromium 打开运行中的 Shelf，通过同源 iframe 执行 DOM 操作并读取实际渲染结果。运行前保存原有 Shelf 存储值，检查完成后恢复。14 项检查全部通过，逐项结果、时间和浏览器标识见 [trial.json](trial.json)：

- 空书架、空标题错误与焦点。
- 输入草稿后切换深色、sage、中文，草稿仍在。
- 添加、标记已读、未读筛选、清除筛选和删除。
- 重新加载后书目、已读状态、主题及语言保留。
- 1280、390、320 CSS px 宽度下，中英文页面无横向文档溢出。

复现：从仓库运行 `npm run trial`，进入命令输出的临时目录，运行 `PORT=4174 node serve.mjs .`，浏览器访问 `http://127.0.0.1:4174`。先输入书名但不添加，切换主题与语言检查草稿，再执行添加、完成、筛选、刷新与删除。布局检查分别使用上述三个宽度。

限制：这些是实际浏览器中的 DOM 驱动检查，不代表真实触控、读屏或原生平台验收。Shelf 只展示中英文；RTL 与长文本的参考检查在 Stillroom 中完成。没有独立模型评审结果。
